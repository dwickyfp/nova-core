## Architecture Rules (NEVER VIOLATE)
1. Immutable storage — NEVER modify Parquet files. UPDATE/DELETE = new MP.
2. MVCC timestamps — every MP MUST have commit_ts, supersedes, superseded_by.
3. Stateless workers — all data in S3, all metadata in FDB.
4. Push-based execution — DataFusion Stream API, NOT Volcano pull.
5. No compaction — GC (delete) only. Optional MP merge for efficiency.
6. No manual cache invalidation — MVCC version is the cache key.
7. FDB is KV store — use range scans, NOT SQL.
8. Pure Rust — no JVM/C++ (Python only via PyO3 for UDF).
